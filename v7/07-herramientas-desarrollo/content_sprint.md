# Este sprint está divido entre tres sesiones

* Sesion 1: Entorno local para el análisis de datos con Python
  * 🖥️ Configura tu terminal, intérprete de Python e IDE
  * 📦 Crea tu primer entorno virtual e instala las librerías esenciales

* Sesion 2: Crea tu primer proyecto de análisis de datos con Python (streamlit)

  * 📊 Construye tu primer dashboard interactivo con Streamlit

* Sesion 3: Comparte tu proyecto con el mundo: GitHub y Deploy en la nube
  * 🐙 Publica tu código en GitHub con tu primer repositorio
  * 🚀 Despliega tu proyecto en la nube con Render y compártelo con el mundo
