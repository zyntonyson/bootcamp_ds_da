# El proyecto consta de diferentes tareas


- **1. Preparación de datos**  
  - Limpieza, validación y estructuración de datos  
  - *Habilidad:* Data cleaning y manejo de datos  
  - *Herramientas:* Python, pandas  

- **2. Análisis de rentabilidad**  
  - Cálculo de KPIs (ingresos, costos, ganancias)  
  - *Habilidad:* Análisis de negocio y métricas clave  
  - *Herramientas:* Python, pandas, SQL  

- **3. Análisis de funnel**  
  - Identificación de pérdidas de usuarios en el proceso  
  - *Habilidad:* Pensamiento analítico y user journey  
  - *Herramientas:* Python, pandas, SQL  

- **4. Análisis de cohortes**  
  - Evaluación de retención y comportamiento de usuarios  
  - *Habilidad:* Análisis temporal y segmentación  
  - *Herramientas:* Python, pandas  

- **5. Test estadístico**  
  - Evaluación del impacto de cambios  
  - *Habilidad:* Inferencia estadística y toma de decisiones  
  - *Herramientas:* Python, análisis estadístico  

- **6. Visualización y comunicación**  
  - Creación de dashboard con insights  
  - *Habilidad:* Storytelling con datos y data visualization  
  - *Herramientas:* Power BI / Tableau
